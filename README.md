# NewsNestBD Live Studio

NewsNestBD-এর জন্য Android লাইভ স্ট্রিমিং অ্যাপ।

## কী করে
- ফোন ক্যামেরা ও মাইক থেকে ফেসবুক ও ইউটিউবে লাইভ
- ফেসবুকে Stream Key দিয়ে অথবা ফেসবুক লগইন করে লাইভ
- অ্যাপের ভেতরেই Facebook App ID ও Client Token সেভ করা যায়

## APK বানানোর নিয়ম
1. রিপোর Actions ট্যাব খুলুন
2. Build Android APK বেছে Run workflow চাপুন
3. শেষ হলে Artifacts থেকে app-debug ডাউনলোড করুন
